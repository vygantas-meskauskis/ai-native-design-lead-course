# Drift Log

> **Drift** = any difference between design-system intent and AI-generated output. Each entry should end with a **rule or context change**, so the same drift doesn't recur (Module 10).

**Root-cause categories:**

1. **Rule:** missing or unclear rule in AGENTS.md
2. **Context:** gap or ambiguity in DESIGN.md, UX.md or the glossary
3. **System:** missing component, variant or token
4. **Figma:** hygiene issue (raw values, bad names, unmapped component, missing description)
5. **Model:** genuine model limitation

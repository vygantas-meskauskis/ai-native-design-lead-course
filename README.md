# From Figma Designer to AI-Native Design Lead

A complete, practical, self-paced course (October 2026) for UX/UI designers moving into a lead role that covers design, AI tooling and design systems.

🌐 **Read it online:** https://vygantas-meskauskis.github.io/ai-native-design-lead-course/

📄 **Or start in markdown:** [00-START-HERE.md](00-START-HERE.md)

## Contents

- **14 modules** ([modules/](modules/)): AI foundations, prompting and critique, AI across the design process, Figma's AI toolkit, AI prototyping, design system foundations, AI-ready design systems (DESIGN.md, Code Connect, AGENTS.md), context engineering (UX.md), design to code with agents and the Figma MCP server, designer–developer collaboration, designing AI features, leading AI adoption, and a capstone with a 90-day plan.
- **14 templates** ([templates/](templates/)): AI log, prompt library, feature brief, DESIGN.md, AGENTS.md, UX.md, context experiment, drift log, design QA checklist, collaboration contract, AI policy, pilot plan, skills matrix and 90-day plan.
- [Glossary](GLOSSARY.md) and [Resources](RESOURCES.md).

About 80 hours, or 12 weeks at 6–7 hours a week.

> Tool-specific details are marked 🔧 and change quickly, so re-check them against the official docs. Sources are linked throughout, mainly NN/G research, Figma's documentation, the W3C DTCG design-token specification and Google Labs' DESIGN.md.
